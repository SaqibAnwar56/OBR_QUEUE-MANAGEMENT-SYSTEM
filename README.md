## 📌 Project Overview

**OBR Queue Management System** is a web-based application designed to digitalize customer queues and streamline organizational workflows. The application features two distinct interfaces:
* 🌐 **Customer Website:** Public interface for queue interaction, feedback submission, and customer operations.
* 🔐 **Admin Portal:** Protected dashboard for system administration, feedback reviews, and record monitoring.
